# 🎵 Catálogo Musical

Este é um sistema de **catálogo musical** desenvolvido em **Node.js** utilizando o padrão **MVC**. O objetivo é permitir o cadastro, visualização e gerenciamento de discos, faixas, artistas e gêneros musicais.
